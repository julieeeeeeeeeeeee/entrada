# Política de Privacidade — Entrada

**Entrada** é um app de e-mail pessoal para Android, de uso individual.

- O app acessa a sua conta do Gmail **somente no seu celular**, usando a API oficial do Gmail, para ler, organizar (arquivar, lixeira, rascunhos, filtros) e enviar e-mails em seu nome, sempre por ação sua.
- **Nenhum dado seu é enviado para servidores do desenvolvedor.** Não há servidor próprio: o app fala direto com o Google.
- O token de acesso fica guardado de forma segura **apenas no seu aparelho** (armazenamento seguro do Android). Ao sair da conta, o acesso é revogado.
- O app não coleta estatísticas, não usa anúncios e não compartilha dados com terceiros.
- O uso e a transferência de informações recebidas das APIs do Google seguem a [Política de Dados do Usuário dos Serviços de API do Google](https://developers.google.com/terms/api-services-user-data-policy), incluindo os requisitos de Uso Limitado.
